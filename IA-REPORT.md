 Uso de Inteligencia Artificial en el Desarrollo de la Estructura HTML
 1. Herramientas Utilizadas y PropósitoDurante la fase inicial de maquetación y estructuración del proyecto Anti-Procrastination Quest, el grupo utilizó modelos de lenguaje basados en IA (como Gemini) como herramienta de apoyo técnico y optimización arquitectónica. El propósito principal de su uso fue acelerar el proceso de prototipado de las vistas y garantizar que el código cumpliera con los estándares modernos de semántica web y accesibilidad exigidos.  
 2. Asistencia en el Código y Prompts Más ÚtilesLa IA asistió principalmente en la conversión de la idea de juego de rol (RPG) a contenedores estructurados y lógicos en HTML5. Los enfoques y consultas que resultaron más efectivos para el desarrollo fueron:  Diseño Modular Multivista: Consultas específicas para mapear la idea de las tres páginas físicas (index.html, personalizacion.html y combate.html) vinculándolas mediante rutas relativas reales para asegurar el correcto funcionamiento en el deploy.  Conversión Temática: Estructuración de tablas nativas y secciones enfocadas a la estética de un videojuego RPG medieval clásico, adaptando las opciones del perfil para que respetaran la temática felina ("razas de gatos").Foco Visual en la Arena: Modificación de las estructuras jerárquicas dentro del campo de batalla para dar prioridad absoluta a la sección de simulación frente al historial de logs.
 3. Correcciones y Decisiones Propias del GrupoEl uso de la IA se limitó a la asistencia, manteniendo el grupo el control total de las decisiones lógicas y del diseño final. Se aplicaron correcciones fundamentales sobre las sugerencias iniciales de la herramienta:  Eliminación de "Divitis": La IA inicialmente propuso una maquetación con un uso excesivo de etiquetas <div> genéricas para lograr los bordes del diseño RPG. El grupo corrigió esto de forma directa, forzando la reestructuración semántica del código mediante el uso de etiquetas apropiadas como <article> para las misiones individuales, <aside> para las barras de estado, <fieldset> para el monitor de combate y <output> para la consola de logs.  Enrutamiento Físico frente a Prototipado: Se descartó la idea de fusionar el código con lógica de ocultamiento dinámico mediante hashes, adaptando la entrega a tres archivos independientes en carpetas organizadas, tal como estipula el reglamento académico.  
 4. Aprendizajes del Proceso: El proceso de co-creación con IA permitió comprender de manera práctica la importancia de la semántica en HTML5. Aprendimos que las herramientas de IA tienden a resolver problemas de diseño de forma rápida usando contenedores neutros (<div>), pero que la optimización para proyectos requiere una revisión crítica humana para incorporar buenas prácticas de accesibilidad (asociación de label e input por ID, legibilidad estructural) y jerarquías limpias que faciliten la futura inyección de lógica con JavaScript.
